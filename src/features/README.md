# Planned feature modules

This directory is reserved for WebAbility implementation modules. It intentionally contains no fake or non-functional scanner code.

Planned modules:
- `journeys/` — journey types, schema, and validation.
- `runner/` — browser lifecycle and step execution.
- `accessibility/` — adapter around a maintained accessibility engine.
- `reports/` — normalized findings and report serialization.

See [the architecture proposal](../../docs/ARCHITECTURE.md) and [roadmap](../../docs/ROADMAP.md). Add modules when implementation and tests support them.
