# Security Policy

## Supported versions

WebAbility is in early development. Security fixes are made against the latest code on the default branch.

## Reporting a vulnerability

Please do not publish exploitable vulnerability details, credentials, cookies, private URLs, or customer data in a public issue.

Use GitHub's private vulnerability reporting feature for this repository if it is enabled. Otherwise, contact the repository owner privately through GitHub before sharing technical details. Include the affected commit or version, impact, and a minimal reproduction where safe.

The current runner is intentionally restricted to loopback targets and same-origin navigation. Please report any way to bypass those restrictions as a security issue.
